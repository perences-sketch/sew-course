# مشروع Recycle Fashion (sew-course) 👗♻️

هذا المشروع عبارة عن صفحة ويب تفاعلية تهدف إلى تعليم وتطوير الملابس والأقمشة المستعملة، كجزء من دورة تدريبية.

## 🌐 رابط الصفحة المباشرة
يمكنك زيارة الصفحة ومشاهدتها مباشرة من هنا:
👉 **[اضغط هنا لفتح صفحة Recycle Fashion](https://perences-sketch.github.io/sew-course/)**

## 🚀 المميزات
- تصميم متجاوب (Responsive) يعمل على جميع الشاشات (الجوال والكمبيوتر).
- واجهة مستخدم مريحة بألوان هادئة (بيج وبني).
- نظام تبويبات (Tabs) سلس.
- **عداد زيارات مباشر** يعرض عدد زوار الصفحة.

## 🛠️ التقنيات المستخدمة
- HTML5
- CSS3
- GitHub Pages (للاستضافة)
